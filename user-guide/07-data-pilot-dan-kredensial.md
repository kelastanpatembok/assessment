# Data Pilot dan Kredensial Undangan

## SMA 3 Yogyakarta

Pilot menggunakan SMAN 3 Yogyakarta (NPSN 20403178). Assignment Paket Lengkap
aktif dan login satu kredensial siswa berhasil diuji, termasuk akses dashboard.

## Batch undangan

Sebanyak 100 kredensial siswa dibuat untuk sekolah dalam surat undangan. Dari
nama yang tidak dapat dicocokkan persis pada direktori, 28 entry sekolah dibuat
manual dengan kota/kabupaten dan Provinsi D.I. Yogyakarta dari surat undangan.
Entry manual dicatat oleh skrip `scripts/provision-invitation-students.mjs`.
Kredensial tidak dicantumkan di panduan atau commit.

Tidak ada akun Guru BK yang dibuat langsung dalam batch ini. Guru BK wajib
melalui pengajuan dan persetujuan superadmin.
